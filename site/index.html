03 / Self-refinement

Use each trial to improve a skill.

Rehearse modules in parallel, locate the failed condition, and refine the responsible skill before joining the sequence again.

  1. Observe

    Read the images and robot feedback.

  2. Diagnose

    Find the failed geometric or physical condition.

  3. Refine

    Change the local grasp, motion, or observation.

  4. Verify

    Run the joined sequence with independent checks.
